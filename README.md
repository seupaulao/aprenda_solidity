# aprenda_solidity
Escrever contratos, aprender solidity e tecnologias correlacionadas

## install foundry

1. curl -L https://getfoundry.sh/install | bash

2. in `~/.bashrc` :

`export PATH="$PATH:/home/pjunior/.foundry/bin"`

3. foundryup

## criar um projeto foundry

`forge init PATH_PROJETO`

## build e test

1. forge build

2. forge test

## testnet localhost
